## ✨ Features

- 🎨 **Modern Blue Gradient Design** — Professional 
  and eye-catching hero section
- 📱 **Fully Responsive** — Perfect on all devices
- 💼 **Projects Showcase** — Interactive portfolio 
  with View All modal popup
- 📋 **Start a Project Form** — Glassmorphism form 
  with Netlify Forms integration
- ⚡ **Smooth Animations** — CSS animations throughout
- 🌙 **Trust Badges** — Response time, consultation, 
  satisfaction guarantees
- 📊 **Stats Counter** — Projects done, satisfaction rate
- 🔗 **Multi-platform** — Linked to Fiverr & Malt profiles

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/Deepan-hub/codenovea.git

# Navigate to project directory
cd codenovea

# Open in browser
open index.html
```

No dependencies needed — pure HTML, CSS & JavaScript!
